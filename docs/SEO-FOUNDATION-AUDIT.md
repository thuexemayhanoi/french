# SEO Foundation Audit & Matrix — fr.rentbikehanoi.com

## Audit snapshot

- Audited: **43 existing HTML pages** on `main`.
- User requested long-form expansion for every created page except Contact.
- **42/42 non-contact foundation pages are now targeted at 1,500–3,000 words** and enforced by QA.
- Contact remains intentionally short and transactional.
- The FAQ remains structured for AI/search answers, while hubs now contain substantial static French copy.
- The 500-article factory is still untouched.

## SEO rules before touching the 500-article matrix

1. **One broad intent = one foundation URL.** Future articles must target narrower long-tail intents.
2. **Hub pages are not placeholder category pages.** Each needs unique introductions, decision guidance, subtopic summaries, FAQs and contextual links.
3. **Do not manufacture prices, stock or model availability.** Only verified business facts may be presented as current.
4. **Permis / legal pages are YMYL.** Use current official sources and show a last-checked date.
5. **Travel pages must re-check road restrictions, ferries and weather-sensitive claims before publishing.**
6. **French copy must be written for French search intent**, not translated literally from English/Vietnamese.
7. **Internal linking target:** each hub should link to all direct child categories + 3–8 contextually related sibling/parent pages once content exists.

## Content templates

### Home
Target 900–1,200 words: proposition de valeur → categories → how rental works → verified prices/examples → location/address → popular vehicle types → popular routes → trust/FAQ → CTA.

### Top-level hub
Target 1,000–1,300 words: definition/overview → who it is for → decision criteria → child category summaries → key comparisons → FAQ → contextual links.

### Child category
Target 800–1,200 words: intent answer → selection criteria → use cases → limits/safety → related models/routes → FAQ → parent/sibling links.

### Trust pages
About 600–800 words, Contact 350–500 words. Strengthen real-business trust, not keyword repetition.

### Legal pages
Write complete policies for the site's real data and business behavior. Do not fabricate contractual clauses.
