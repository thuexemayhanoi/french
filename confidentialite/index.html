Politique de confidentialité

Cette politique décrit ce qui se passe réellement lorsque vous consultez fr.rentbikehanoi.com, utilisez l’assistant des pages ou contactez Thuê xe máy Nguyễn Hà. Elle a été établie à partir du fonctionnement du site et signale ce qui reste à préciser. Dernière mise à jour : 29 octobre 2026.

En bref

  • Aucun compte, aucun formulaire de contact ou de réservation, aucune lettre d’information.
  • Aucun outil de mesure d’audience, de publicité ou de suivi, et aucun cookie créé par le code du site.
  • Pages, scripts, styles et images sont servis depuis fr.rentbikehanoi.com : rien n’est chargé depuis un autre domaine.
  • Une seule donnée est enregistrée dans votre navigateur : votre choix de thème clair ou sombre, si vous utilisez le bouton prévu.
  • L’assistant traite vos questions dans votre navigateur ; le texte tapé n’est ni envoyé ni enregistré.
  • L’hébergeur, GitHub Pages, journalise l’adresse IP des visiteurs pour des raisons de sécurité.
  • Si vous appelez ou écrivez sur Zalo ou WhatsApp, vos coordonnées et vos messages parviennent à l’établissement par ces services.

Qui est responsable du site

Le site est celui de Thuê xe máy Nguyễn Hà, Ngõ 5 Nguyễn Văn Cừ, Bồ Đề, Long Biên, Hà Nội (gần Bến xe Gia Lâm). Pour toute question sur cette politique ou sur des informations vous concernant, joignez l’établissement par téléphone au 0334 699 969 (+84 334 699 969), sur Zalo ou sur WhatsApp, de 09:00 à 21:00, heure de Hanoi. Aucune adresse e-mail n’est publiée à ce jour. La page Contact reprend ces coordonnées.

Ce que le site enregistre dans votre navigateur

Le bouton « Changer le thème » (◐) de l’en-tête bascule entre un affichage clair et un affichage sombre. Lorsque vous l’utilisez, le site enregistre la valeur « light » ou « dark » dans le stockage local de votre navigateur (localStorage), sous le nom « theme », pour conserver ce choix d’une page à l’autre. Cette valeur reste sur votre appareil, n’est pas transmise au serveur et ne permet pas de vous identifier. Pour l’effacer, supprimez les données du site fr.rentbikehanoi.com dans les réglages de votre navigateur.

Le code du site n’écrit aucune autre donnée : pas de cookie, pas de stockage de session, pas d’identifiant de visiteur. L’indication « Ouvert » ou « Fermé » affichée dans l’en-tête est calculée par votre navigateur à partir de l’heure de Hanoi, sans rien envoyer.

Hébergement du site par GitHub Pages

fr.rentbikehanoi.com est un site statique publié avec GitHub Pages, le service d’hébergement de GitHub. Pour afficher une page, votre navigateur envoie une requête aux serveurs de GitHub, comme pour n’importe quel site : elle comporte notamment votre adresse IP, l’adresse de la page demandée et des informations techniques sur votre navigateur.

Selon la documentation de GitHub Pages, consultée le 29 octobre 2026, l’adresse IP de chaque visiteur d’un site GitHub Pages est journalisée et conservée à des fins de sécurité, que le visiteur soit connecté à GitHub ou non. Ce traitement relève de GitHub et de sa déclaration de confidentialité, dans sa version en vigueur depuis le 27 avril 2026. Le site n’y ajoute aucun outil de statistiques.

La page d’accueil contient par ailleurs une balise de vérification destinée à Google Search Console. Cette balise est un simple texte dans le code de la page : elle ne charge aucun script et ne transmet rien depuis votre navigateur.

L’assistant : ce que deviennent vos questions

L’assistant, ouvert par le bouton en bas à droite des pages, est un programme qui s’exécute entièrement dans votre navigateur. Voici ce qui se passe lorsque vous l’utilisez :

  • à l’ouverture de la fenêtre, votre navigateur télécharge depuis ce site un fichier d’index contenant des extraits des pages publiées (/assets/chat/search-index.json) ; l’adresse de ce fichier est toujours la même et ne contient pas votre question ;
  • votre question est comparée à cet index et à quelques réponses préparées (horaires, adresse, contact, tarifs indicatifs), directement sur votre appareil ;
  • le texte tapé n’est envoyé à aucun serveur, ni à l’établissement, ni à un service d’intelligence artificielle, et il n’est pas enregistré : la conversation disparaît lorsque vous rechargez ou quittez la page ;
  • l’assistant ne transmet aucune demande au loueur : pour être recontacté, appelez ou écrivez vous-même.

N’y saisissez pas de données personnelles : l’assistant n’en a pas besoin pour répondre. Ses limites sont décrites dans les conditions d’utilisation du site.

Quand vous contactez Thuê xe máy Nguyễn Hà

Les liens d’appel, Zalo et WhatsApp, présents dans les pages, le pied de page et le menu de contacts rapides en bas à gauche, vous font quitter le site :

  • le lien d’appel ouvre l’application téléphone de votre appareil ; l’établissement voit ensuite votre numéro, selon les réglages de votre ligne ;
  • le lien Zalo ouvre zalo.me ; Zalo traite les données selon ses informations sur la confidentialité ;
  • le lien WhatsApp ouvre wa.me ; WhatsApp traite les données selon sa politique de confidentialité ;
  • le bouton « Carte » ouvre dans Google Maps une recherche de l’adresse du loueur ; ce que Google enregistre relève de ses règles de confidentialité.

Aucune information n’est transmise à ces services avant votre clic : ce sont de simples liens, sans module intégré à la page. Au moment du clic, votre navigateur peut indiquer au service ouvert que vous arrivez de fr.rentbikehanoi.com.

Une fois la conversation engagée, l’établissement reçoit ce que vous lui communiquez par ces applications : numéro de téléphone, nom de profil, messages, photos ou documents éventuels. La durée de conservation de ces échanges et les personnes qui y ont accès ne sont pas encore décrites ici. Posez la question avant d’envoyer une pièce d’identité, et n’envoyez une copie de passeport ou de permis que si elle vous est réellement demandée pour votre location.

Vos demandes sur vos informations

En dehors des journaux techniques de l’hébergeur décrits plus haut, le site ne conserve aucune donnée vous concernant, hormis la préférence de thème enregistrée dans votre navigateur, que vous pouvez effacer vous-même. Pour les échanges que vous avez eus avec l’établissement, vous pouvez lui demander par les mêmes canaux quelles informations il conserve, les faire corriger ou demander leur suppression. Indiquez le numéro ou le compte utilisé pour vos messages afin qu’il retrouve l’échange. Le délai de réponse et la durée de conservation de ces échanges ne sont pas encore publiés : demandez-les directement.

Pour les journaux de l’hébergeur, adressez-vous à GitHub selon les modalités de sa déclaration de confidentialité. Pour Zalo, WhatsApp ou Google, utilisez les réglages et les contacts prévus par chacun de ces services.

Questions fréquentes

Le site utilise-t-il des cookies ?

Le code du site ne crée aucun cookie. Seul votre choix de thème clair ou sombre peut être enregistré, dans le stockage local de votre navigateur.

Le site utilise-t-il Google Analytics ou un pixel publicitaire ?

Non. Aucun outil de mesure d’audience, de publicité ou de suivi n’est intégré aux pages.

Mes questions à l’assistant sont-elles enregistrées ?

Non. Elles sont traitées dans votre navigateur, ne sont envoyées à aucun serveur et disparaissent lorsque vous quittez la page.

Comment faire supprimer mes messages ?

Contactez l’établissement par téléphone, Zalo ou WhatsApp en indiquant le numéro ou le compte utilisé. Les messages restent aussi soumis aux règles de Zalo ou de WhatsApp.
