Politique de confidentialité

Objet de cette politique

Cette politique explique comment le site fr.rentbikehanoi.com traite les informations lorsqu’un visiteur consulte les pages, utilise les liens de contact ou choisit un réglage d’affichage. Le site est un blog statique publié via GitHub Pages et présente des informations sur la location de motos à Hanoi, les modèles, les prix, la sécurité et les itinéraires. L’objectif de cette page est de décrire les pratiques de manière compréhensible, sans prétendre qu’aucune donnée technique n’existe sur Internet.
